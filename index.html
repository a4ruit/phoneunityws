Required stuff:

An empty 3D Unity project
A VSCode folder
Existing GitHub Account

What we will learn:

The workflow process on how we can use WebSockets to drive interactions in Unity so that you can walk away with a foundation to tinker around with.

Part 1 — Setup

Goal: your phone talking to Unity through your own free server.

(a) Put the site online

Add the server files to your folder, push to GitHub, then deploy free on Render for an https://…onrender.com address.

Your files

Add these to your folder:

server.js — the relay
package.json — its setup
index.html — the web page

Without these, Render has nothing to run.

GitHub

Make a repo at github.com/new. Then push your folder to it:

git add .
git commit -m "site"
git push

Render

First let Render see the repo: Credentials → Configure in GitHub, tick your repo, Save.

Then New → Web Service, pick it. Set Language to Node, Build npm install, Start node server.js.

Folder layout

One flat folder — no subfolders.

your-repo/
├── package.json
├── server.js        ← Render runs this
├── index.html       ← the web page, served at "/"
└── styles.css

Two lines point Render at server.js:
Render Start Command: node server.js
package.json: "start": "node server.js"

package.json — the dependency + start command 
{
  "name": "phone-unity-relay",
  "version": "1.0.0",
  "private": true,
  "main": "server.js",
  "scripts": {
    "start": "node server.js"
  },
  "dependencies": {
    "ws": "^8.18.0"
  }
}
server.js — serves the page & relays messages by room 
'use strict';

const http = require('http');
const fs = require('fs');
const path = require('path');
const { WebSocketServer } = require('ws');

const PORT = process.env.PORT || 3000;
const ROOT = __dirname;

const MIME = {
  '.html': 'text/html; charset=utf-8',
  '.js': 'text/javascript; charset=utf-8',
  '.css': 'text/css; charset=utf-8'
};

// ---- serve the page ----
const server = http.createServer((req, res) => {
  const url = new URL(req.url, `http://${req.headers.host}`);

  if (url.pathname === '/healthz') {
    res.writeHead(200).end('ok');
    return;
  }

  const rel = url.pathname === '/' ? 'index.html' : url.pathname.replace(/^\/+/, '');
  const file = path.join(ROOT, path.normalize(rel));
  if (!file.startsWith(ROOT)) { res.writeHead(403).end('no'); return; }

  fs.readFile(file, (err, data) => {
    if (err) { res.writeHead(404).end('not found'); return; }
    res.writeHead(200, { 'Content-Type': MIME[path.extname(file)] || 'text/plain' });
    res.end(data);
  });
});

// ---- websocket relay ----
const wss = new WebSocketServer({ server, path: '/ws' });
const rooms = new Map();

function getRoom(name) {
  if (!rooms.has(name)) rooms.set(name, new Set());
  return rooms.get(name);
}

function broadcast(room, sender, payload) {
  const text = JSON.stringify(payload);
  for (const client of room) {
    if (client !== sender && client.readyState === client.OPEN) {
      client.send(text);
    }
  }
}

wss.on('connection', (ws, req) => {
  const url = new URL(req.url, `http://${req.headers.host}`);
  const name = (url.searchParams.get('room') || 'default').slice(0, 64);
  const room = getRoom(name);
  room.add(ws);

  ws.on('message', (raw) => {
    let msg;
    try { msg = JSON.parse(raw.toString()); } catch { return; }
    if (!msg || typeof msg !== 'object') return;
    // Pass anything through to everyone else in the same room.
    broadcast(room, ws, msg);
  });

  ws.on('close', () => {
    room.delete(ws);
    if (room.size === 0) rooms.delete(name);
  });
});

server.listen(PORT, () => console.log(`relay listening on :${PORT}`));

(b) Open it on your phone

On your phone go to your …onrender.com address. HTTPS is what will later let the phone share its sensors.

(c) Point Unity at it

In the HeadingReceiver component, set the server to wss://…onrender.com/ws, then press Play.

You'll know it works when…

You turn your phone and the view turns with you in Unity. That's the whole pipe — everything else is tinkering.
