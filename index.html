Required stuff:

Unity installed (Unity Hub)
VSCode installed
Existing GitHub Account

What we will learn:

The workflow process on how we can use WebSockets to drive interactions in Unity so that you can walk away with a foundation to tinker around with.

Part 1: Setup

Goal: your phone talking to Unity through your own free server.

(a) Set up your folder in VSCode

Make a new folder and open it in VSCode (File → Open Folder). Create two files to start:

1. index.html (the page)
2. styles.css (how it looks)

Good practice: get a plain page working before adding any server code.

index.html: a starting page 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Phone + Unity</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <h1>Phone + Unity</h1>
</body>
</html>
styles.css: basic styling 
body {
  font-family: sans-serif;
  text-align: center;
  padding: 40px;
}

(b) Add the server files

Next to your page, create two more files:

server.js: the relay
package.json: its setup

These are what Render will run.

package.json: the dependency + start command 
{
  "dependencies": { "ws": "^8.18.0" },
  "scripts": { "start": "node server.js" }
}
server.js: serves the page & relays messages 
const http = require('http');
const fs = require('fs');
const { WebSocketServer } = require('ws');

// Serve the web page.
const server = http.createServer((req, res) => {
  const file = req.url === '/' ? '/index.html' : req.url;
  fs.readFile(__dirname + file, (err, data) => {
    if (err) { res.writeHead(404).end('not found'); return; }
    if (file.endsWith('.css')) res.setHeader('Content-Type', 'text/css');
    res.end(data);
  });
});

// Relay every message to all the other connected clients.
const wss = new WebSocketServer({ server, path: '/ws' });

wss.on('connection', (ws) => {
  ws.on('message', (msg) => {
    for (const client of wss.clients) {
      if (client !== ws && client.readyState === client.OPEN) {
        client.send(msg.toString());
      }
    }
  });
});

server.listen(process.env.PORT || 3000);

Your folder now

Four files, one flat folder, no subfolders.

your-folder/
├── index.html       ← the web page
├── styles.css
├── server.js        ← Render runs this
└── package.json

(c) Put the site online

Push your folder to GitHub, then deploy it free on Render for an https://…onrender.com address.

GitHub

Make an empty repo at github.com/new. Then in VSCode's terminal, run these one line at a time:

git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin <your repo url>
git push -u origin main

One at a time: each line depends on the one before it. Pasting all at once jumbles the order.

Render

First let Render see the repo: Credentials → Configure in GitHub, tick your repo, Save.

Then New → Web Service, pick it. Set Language to Node, Build npm install, Start node server.js.

(d) Checkpoint: open your site

Open your https://your-name.onrender.com address in a browser, on your computer or your phone. You should see your Phone + Unity page. That confirms the server is working.

Keep this address handy. Unity needs it soon.

(e) Prepare a spawn button on our web page

Add a button to your index.html that sends a spawn message to your server. This one is live, press it to see what it does:

Add the code below to your own page.

Add this to index.html, before </body> 
<button id="spawnBtn">Spawn a box</button>

<script>
  var ws = new WebSocket('wss://' + location.host + '/ws');

  document.getElementById('spawnBtn').onclick = function () {
    ws.send(JSON.stringify({ type: 'spawn' }));
  };
</script>

Update your site

You changed index.html, so push the update. Render redeploys on its own:

git add .
git commit -m "this is an update note and we're adding a button in it"
git push

This is the everyday flow after that first setup: add, commit, push.

(f) Make a new Unity project

Open Unity Hub, click New Project, pick the 3D template, name it, and Create. Wait for it to open.

(g) Add the spawner to Unity

In your new project:

1. Make a folder Assets/Scripts and add BoxSpawner.cs (code below).
2. GameObject → Create Empty.
3. Drag BoxSpawner.cs onto it.
4. Make your WebSocket address: change your site's https to wss and add /ws (wss://your-name.onrender.com/ws). Paste it into Server Url.

No plugins needed. ClientWebSocket is built into Unity.

BoxSpawner.cs: connects and drops a cube on "spawn" 
using System;
using System.Net.WebSockets;
using System.Text;
using System.Threading;
using System.Threading.Tasks;
using UnityEngine;

public class BoxSpawner : MonoBehaviour
{
    [Tooltip("wss://your-service.onrender.com/ws")]
    public string serverUrl = "wss://your-service.onrender.com/ws";

    ClientWebSocket socket;
    int pending;                        // boxes waiting to spawn
    readonly object gate = new object();

    async void Start()
    {
        socket = new ClientWebSocket();
        await socket.ConnectAsync(new Uri(serverUrl), CancellationToken.None);
        Debug.Log("Connected");
        _ = ReceiveLoop();
    }

    async Task ReceiveLoop()
    {
        var buffer = new byte[1024];
        try
        {
            while (socket.State == WebSocketState.Open)
            {
                var result = await socket.ReceiveAsync(new ArraySegment<byte>(buffer), CancellationToken.None);
                string text = Encoding.UTF8.GetString(buffer, 0, result.Count);
                if (text.Contains("spawn")) lock (gate) { pending++; }
            }
        }
        catch { }
    }

    void Update()
    {
        // Boxes must be created on Unity's main thread, so we do it here.
        lock (gate)
        {
            while (pending > 0) { pending--; SpawnBox(); }
        }
    }

    void SpawnBox()
    {
        var box = GameObject.CreatePrimitive(PrimitiveType.Cube);
        box.transform.position = new Vector3(UnityEngine.Random.Range(-4f, 4f), 6f, UnityEngine.Random.Range(-4f, 4f));
        box.AddComponent<Rigidbody>();
    }

    void OnDestroy()
    {
        socket?.Dispose();
    }
}

(h) Press Play and test

Press Play in Unity. Then open your onrender.com page and click the Spawn a box button you made. A cube drops into the scene.

That's the whole pipe: browser to server to Unity. Everything else is tinkering.
