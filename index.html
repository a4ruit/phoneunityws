What we will learn:

The workflow process on how we can use WebSockets to drive interactions in Unity so that you can walk away with a foundation to tinker around with.

Part 1: Setup

Goal: your phone talking to Unity through your own free server.

(a) Set up your folder in VSCode

Make a new folder and open it in VSCode (File → Open Folder). Create two files to start:

1. index.html (the page)
2. styles.css (how it looks)

Good practice: get a plain page working before adding any server code.

index.html: a starting page 
<!DOCTYPE html>
<html lang="en">

  <link rel="stylesheet" href="styles.css">

  <h1>Phone + Unity</h1>
</body>
</html>
styles.css: basic styling

  font-family: sans-serif;
  text-align: center;
  padding: 40px;
}

(b) Add the server files

Next to your page, create two more files:

server.js: the relay
package.json: its setup

These are what Render will run.

package.json: the dependency + start command 
{
  "dependencies": { "ws": "^8.18.0" },
  "scripts": { "start": "node server.js" }
}
server.js: serves the page & relays messages 
const http = require('http');
const fs = require('fs');
const { WebSocketServer } = require('ws');

// Serve the web page.
const server = http.createServer((req, res) => {
  const file = req.url === '/' ? '/index.html' : req.url;
  fs.readFile(__dirname + file, (err, data) => {
    if (err) { res.writeHead(404).end('not found'); return; }
    if (file.endsWith('.css')) res.setHeader('Content-Type', 'text/css');
    res.end(data);
  });
});

// Relay every message to all the other connected clients.
const wss = new WebSocketServer({ server, path: '/ws' });

wss.on('connection', (ws) => {
  ws.on('message', (msg) => {
    for (const client of wss.clients) {
      if (client !== ws && client.readyState === client.OPEN) {
        client.send(msg.toString());
      }
    }
  });
});

server.listen(process.env.PORT || 3000);

Your folder now

Four files, one flat folder, no subfolders.

your-folder/
├── index.html       ← the web page
├── styles.css
├── server.js        ← Render runs this
└── package.json

(c) Put the site online

Push your folder to GitHub, then deploy it free on Render for an https://…onrender.com address.

GitHub

Make an empty repo at github.com/new. Then in VSCode's terminal, run these one line at a time:

git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin <your repo url>
git push -u origin main

One at a time: each line depends on the one before it. Pasting all at once jumbles the order.

Render

First let Render see the repo: Credentials → Configure in GitHub, tick your repo, Save.

Then New → Web Service, pick it. Set Language to Node, Build npm install, Start node server.js.

(d) Checkpoint: open your site

Open your https://your-name.onrender.com address in a browser, on your computer or your phone. You should see your Phone + Unity page. That confirms the server is working.

Keep this address handy. Unity needs it soon.

(f) Make a new Unity project

Open Unity Hub, click New Project, pick the 3D template, name it, and Create. Wait for it to open.

(g) Add the spawner to Unity

In your new project:

1. Make a folder Assets/Scripts and add BoxSpawner.cs (code below).
2. GameObject → Create Empty.
3. Drag BoxSpawner.cs onto it.
4. Make your WebSocket address: change your site's https to wss and add /ws (wss://your-name.onrender.com/ws). Paste it into Server Url.

No plugins needed. ClientWebSocket is built into Unity.

BoxSpawner.cs: connects and drops a cube on "spawn" 
using System;
using System.Net.WebSockets;
using System.Text;
using System.Threading;
using System.Threading.Tasks;
using UnityEngine;

public class BoxSpawner : MonoBehaviour
{
    [Tooltip("wss://your-service.onrender.com/ws")]
    public string serverUrl = "wss://your-service.onrender.com/ws";

    ClientWebSocket socket;
    int pending;                        // boxes waiting to spawn
    readonly object gate = new object();

    async void Start()
    {
        socket = new ClientWebSocket();
        await socket.ConnectAsync(new Uri(serverUrl), CancellationToken.None);
        Debug.Log("Connected");
        _ = ReceiveLoop();
    }

    async Task ReceiveLoop()
    {
        var buffer = new byte[1024];
        try
        {
            while (socket.State == WebSocketState.Open)
            {
                var result = await socket.ReceiveAsync(new ArraySegment<byte>(buffer), CancellationToken.None);
                string text = Encoding.UTF8.GetString(buffer, 0, result.Count);
                if (text.Contains("spawn")) lock (gate) { pending++; }
            }
        }
        catch { }
    }

    void Update()
    {
        // Boxes must be created on Unity's main thread, so we do it here.
        lock (gate)
        {
            while (pending > 0) { pending--; SpawnBox(); }
        }
    }

    void SpawnBox()
    {
        var box = GameObject.CreatePrimitive(PrimitiveType.Cube);
        box.transform.position = new Vector3(UnityEngine.Random.Range(-4f, 4f), 6f, UnityEngine.Random.Range(-4f, 4f));
        box.AddComponent<Rigidbody>();
    }

    void OnDestroy()
    {
        socket?.Dispose();
    }
}

(h) Press Play and test

Press Play in Unity. Then open your onrender.com page and click the Spawn a box button you made. A cube drops into the scene.

That's the whole pipe: browser to server to Unity. Everything else is tinkering.

Part 2: Tinkering (if you finish early)

The foundation is done. Everything past here is bonus: for if you finish early, or to explore on your own afterwards. Use the phone's own features to drive what happens in Unity.

The pattern

Nothing new to deploy. You only change what the phone sends and what Unity does with it. The server relays any message untouched.

(a) Read the phone's tilt

Now we tinker with the phone's tilt. We turn how far it is tipped into two numbers, draw an arrow so we can see it, and send that to Unity.

In index.html, before </body> 
<button id="tiltBtn">Enable tilt</button>
<canvas id="tiltArrow" width="160" height="160"></canvas>
<script src="tilt.js"></script>
New file tilt.js 
var ws = new WebSocket('wss://' + location.host + '/ws');
var ctx = document.getElementById('tiltArrow').getContext('2d');

document.getElementById('tiltBtn').onclick = function () {
  // iOS needs permission, asked from inside a tap.
  if (typeof DeviceOrientationEvent.requestPermission === 'function') {
    DeviceOrientationEvent.requestPermission();
  }
  window.addEventListener('deviceorientation', onTilt);
};

function onTilt(e) {
  var x = Math.max(-1, Math.min(1, e.gamma / 45));   // left / right
  var y = Math.max(-1, Math.min(1, e.beta  / 45));   // front / back
  drawArrow(x, y);
  ws.send(JSON.stringify({ type: 'tilt', x: x, y: y }));
}

function drawArrow(x, y) {
  ctx.clearRect(0, 0, 160, 160);
  ctx.strokeStyle = '#111';
  ctx.lineWidth = 6;
  ctx.beginPath();
  ctx.moveTo(80, 80);
  ctx.lineTo(80 + x * 60, 80 + y * 60);
  ctx.stroke();
}

(b) Roll a cube in Unity

In your project:

1. Add a Plane (floor) and a Cube with a Rigidbody.
2. Put TiltRoller.cs (below) on the cube.
3. Paste your wss://…onrender.com/ws into Server Url.
4. Point the camera straight down at the plane.

TiltRoller.cs: pushes the cube in the tilt direction 
using System;
using System.Net.WebSockets;
using System.Text;
using System.Threading;
using System.Threading.Tasks;
using UnityEngine;

[RequireComponent(typeof(Rigidbody))]
public class TiltRoller : MonoBehaviour
{
    [Tooltip("wss://your-service.onrender.com/ws")]
    public string serverUrl = "wss://your-service.onrender.com/ws";
    public float strength = 20f;

    Rigidbody body;
    float tiltX, tiltZ;
    ClientWebSocket socket;

    async void Start()
    {
        body = GetComponent<Rigidbody>();
        socket = new ClientWebSocket();
        await socket.ConnectAsync(new Uri(serverUrl), CancellationToken.None);
        Debug.Log("Connected");
        _ = ReceiveLoop();
    }

    async Task ReceiveLoop()
    {
        var buffer = new byte[1024];
        try
        {
            while (socket.State == WebSocketState.Open)
            {
                var r = await socket.ReceiveAsync(new ArraySegment<byte>(buffer), CancellationToken.None);
                var msg = JsonUtility.FromJson<Tilt>(Encoding.UTF8.GetString(buffer, 0, r.Count));
                if (msg != null && msg.type == "tilt") { tiltX = msg.x; tiltZ = msg.y; }
            }
        }
        catch { }
    }

    void FixedUpdate()
    {
        // The one line to tinker with: tilt becomes a push on the cube.
        body.AddForce(new Vector3(tiltX, 0f, tiltZ) * strength);
    }

    void OnDestroy() { socket?.Dispose(); }

    [Serializable] class Tilt { public string type; public float x; public float y; }
}

(c) Press Play and tilt

Press Play, then tilt your phone like a tray. The cube rolls the way you tip it. A phone sensor is now driving Unity in real time.

Now try

Change one thing and watch what happens:

• Raise strength for faster rolls.
• Drop a stack of cubes for it to smash into.
• Swap AddForce for AddTorque so tilt spins it.
• Send a different sensor: a shake, mic volume, a finger drag.

Same pipe every time. Only the message and the reaction change.

(3) Roll the ball in Unity

Put BowlingBall.cs (below) on the ball and set its Server Url. Tilt to aim, press Bowl to throw, press R to reset.

BowlingBall.cs: aim with tilt, launch on bowl 
using System;
using System.Net.WebSockets;
using System.Text;
using System.Threading;
using System.Threading.Tasks;
using UnityEngine;

[RequireComponent(typeof(Rigidbody))]
public class BowlingBall : MonoBehaviour
{
    public string serverUrl = "wss://your-service.onrender.com/ws";
    public float power = 15f;      // speed down the lane
    public float aimRange = 4f;    // how far tilt steers left / right

    Rigidbody body;
    Vector3 start;
    float aim;                     // -1..1 from the phone tilt
    bool bowl;
    ClientWebSocket socket;

    async void Start()
    {
        body = GetComponent<Rigidbody>();
        start = transform.position;
        socket = new ClientWebSocket();
        await socket.ConnectAsync(new Uri(serverUrl), CancellationToken.None);
        _ = ReceiveLoop();
    }

    async Task ReceiveLoop()
    {
        var buffer = new byte[1024];
        try
        {
            while (socket.State == WebSocketState.Open)
            {
                var r = await socket.ReceiveAsync(new ArraySegment<byte>(buffer), CancellationToken.None);
                string text = Encoding.UTF8.GetString(buffer, 0, r.Count);
                if (text.Contains("bowl")) bowl = true;
                else if (text.Contains("tilt")) aim = JsonUtility.FromJson<Tilt>(text).x;
            }
        }
        catch { }
    }

    void Update()
    {
        if (bowl)
        {
            bowl = false;
            // Roll down the lane (+Z), steered sideways by the aim.
            body.velocity = new Vector3(aim * aimRange, 0f, power);
        }

        if (Input.GetKeyDown(KeyCode.R))   // reset the ball
        {
            body.velocity = Vector3.zero;
            body.angularVelocity = Vector3.zero;
            transform.position = start;
        }
    }

    [Serializable] class Tilt { public string type; public float x; }
    void OnDestroy() { socket?.Dispose(); }
}
